# Threat model

Method: STRIDE-style dataflow review with explicit memory/lifecycle hazards. Design analysis, not a security certification. Assets: model integrity, request KV contents, output attribution, memory capacity, reproducible evidence and public source integrity. Actors: trusted host/operator; untrusted token/record sender; malicious dependency; accidental faulty executor. Trust zones: local preparation, runtime process, client data, CI and publication.

|ID|Threat|Precondition|Impact|Likelihood|Control|Residual risk|Evidence|
|---|---|---|---|---|---|---|---|
|TH-001|Spoofed request owner|Untrusted adapter trusts a body tenant|Cross-request access|Medium|Trusted CLI boundary; optional adapter binds auth to owner and ignores supplied authority|Host remains trusted|AC-014|
|TH-002|Stale page handle / use after reuse|Freed page reassigned|Old request reads new request state|High|Owner+generation checks, RAII lifecycle, no generation wrap|Bugs in the implementation|AC-003/004|
|TH-003|Cache remanence|Nonzero page becomes free|Cross-request plaintext inference state leak|High|Zero before reassignment; deny access to free pages|No OS core-dump or privileged-host defense|AC-004|
|TH-004|Late completion after cancellation|Compute completion races terminal state|Post-cancel token exposure or double release|High|Single actor; generation recheck for async backend; terminal exactly once|Already emitted tokens cannot be retracted|AC-005/007|
|TH-005|Allocation overflow / malformed model|Untrusted tensor metadata|OOM, out-of-bounds access, crash|High|Checked product arithmetic, shape allowlist, file length and finite-value checks|C++ parser needs fuzz/sanitizer coverage|AC-011/017|
|TH-006|Malformed protocol / oversized prompt|Host supplies bad token record|Crash or resource exhaustion|High|Bound lengths/counts before parsing; reject invalid token IDs|Host can still kill process|AC-009/010|
|TH-007|Resource monopoly|Long prompt and repeated submissions|Other requests starve|Medium|Admission credits, finite sequence caps, chunked prefill, ready rotation|Compute cost per token is not identical|AC-006/008/009|
|TH-008|Cache timing side channel|Shared machine / cache optimizations|Information about another request|Medium|No prefix sharing; no latency confidentiality claim|Scheduler/resource timing remains observable|Boundary review; no proof of timing safety|
|TH-009|Unsafe checkpoint deserialization|Pickle or remote code enabled|Arbitrary code execution|High|Only known safetensors tensors; trust_remote_code false; immutable source revision and hashes|Trusted upstream or converter compromise|AC-012/013/018|
|TH-010|Supply chain and malicious repo instructions|Dependency or retrieved file compromised|Secret theft/build compromise|Medium|Minimal runtime deps, pinned CI actions, read-only PR permissions, no secret-bearing untrusted CI|Compiler/toolchain compromise out of scope|AC-018|
|TH-011|Evidence forgery / selective reporting|Agent controls code and documents|Misleading engineering claims|High|Machine runner, source hashes, immutable contracts, negative controls, independent CI review|Same actor can edit all local trust roots; hashes are not signatures|AC-019/023/024|
|TH-012|Report XSS|Trace string contains markup|Script runs when reviewer opens report|Medium|html.escape, no scripts/external resources, semantic static HTML|Browser vulnerabilities out of scope|AC-015|
|TH-013|Confused deputy / SSRF|Worker accepts client model path or URL|Private file or network exfiltration|High|Engine takes model path only from trusted process launch; no URL fetch, tools or client-selected files|Host can already read files|AC-010/014|
|TH-014|Model prompt injection/tool misuse|Generated text interpreted as instructions by consumer|Unsafe downstream action|Medium|Runtime emits data only; no tool execution; downstream application owns policy|This runtime cannot prevent an application executing model text|Document non-goal; negative tool-surface audit|
|TH-015|Concurrent request identity replay|Reused IDs after terminal or restart|Output attribution confusion|Medium|Session-bound handles and bounded terminal ledger; explicit restart semantics|No durable request result store|AC-020/021|
|TH-016|Unsafe optional BLAS threading|Nested worker/library threads|Oversubscription and unstable latency|Medium|Pin one-thread baseline; record BLAS flags; separate optimized runs|OS scheduling noise remains|AC-019|

Authentication, workload identity and delegated authority are not invented for the local kernel. The CLI caller is the trusted host; tenant IDs alone are not authentication. Any adapter is a separate boundary requiring real tests. Filesystem/process/network sandbox escape is not claimed to be prevented because the engine is not a hostile-code sandbox. Do not use a model or input that requires executing code. Container deployment reduces accidental exposure but is not presented as a complete isolation proof.
