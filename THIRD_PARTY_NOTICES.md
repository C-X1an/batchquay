Original BatchQuay implementation is MIT-licensed. No model weights, upstream runtime implementation, employer code, private dataset or supplied resume is distributed here. Tiny weights are generated by `tools/fixture.py`; token inputs are synthetic, not customer conversations.

The separately downloaded HuggingFaceTB/SmolLM2-135M checkpoint is labelled Apache-2.0. Preserve its original license/notice when distributing any derived weight artifact; this repository distributes none. `models/manifest.json` pins the revision and independently obtained upstream weight digest. Real local numerical conformance has executed; final source-bound release evidence remains a separate gate.

Development/reference dependencies are installed separately. The [resolved license policy](verification/dependency_license_policy.json) records the exact 35 Windows CPU reference distributions, declared licenses and 190 installed notice-file hashes. It approves their verification use; package wheels/source are not redistributed. Certifi and tqdm include MPL terms and remain separate unmodified verification dependencies.

Its Apache-2.0 [license text](docs/licenses/tokenizers-0.22.2-LICENSE.txt) and source/member digests are retained in the policy. `make security-online` checks actual installed versions/notice bytes and audits all 35 locked packages.
